# MCMC-Metropolis-Hastings
Resolution for a linear model using a Metropolis Hastings (MCMC) algorithm

## Detailed information about the program, including instructions and the results of the analysis -> [report.pdf](report.pdf)

### What does the program do?
- Define the model, the likelihood and the prior
- Calculate the posterior from the previous functions
- Obtain through the Metropolis Hastings algorithm the parameters of the model and its uncertainties
- Plot the points of the chain with the covariance ellipses, the regression with the input points and the evolution of the parameters through the steps taken by the algorithm
